# searxng-notebooks

Local SearXNG setup notes and scripts for a small, domestic-engine search stack.

- Maintained by: Yansui
- License: MIT

## Quick start
1. Start Docker.
2. Copy `settings.yml` into your SearXNG config directory.
3. Run `./run.sh`.
4. Open `http://localhost:8080`.
